# Reference sources

Every reference image under `refs/` has a row here — where it came from, on what terms, and what was made from it. A reference PNG claims integrity (its sha256) and this row, never regeneration: the row is where its origin and its licence live, and a PNG without one is a file nobody can account for, which is why `forge verify` fails on it. Add the row when you add the image; the ledger is the answer to "can we ship this?" and has to be answerable from this file alone.
