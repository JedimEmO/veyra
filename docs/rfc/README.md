# RFCs

One document per delivery, written when the delivery lands, recording what was
built, why, what was chosen over what, and what was left out on purpose. ADRs
(`docs/adr`) record single decisions and are referenced from here; the plan
(`docs/PLAN.md`) is the forward-looking document and is rewritten as work
proceeds. An RFC is never rewritten: a later delivery that changes a choice
gets its own RFC that names the one it supersedes.
